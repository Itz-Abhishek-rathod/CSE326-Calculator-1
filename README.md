# RunMetric 🏃

### Running and Jogging Pace, Distance and Speed Calculator

RunMetric is a responsive and interactive frontend web application designed to help runners and joggers easily calculate their **pace, distance, speed, and running time**.

## 🚀 Features

- Calculate running pace, distance, speed, and time.
- Quick distance presets for 5K, 10K, and Half Marathon.
- Display calculated running results instantly.
- View split times and a visual progress graph.
- Responsive design for mobile, tablet, and desktop.
- Simple and user-friendly interface.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 💻 How to Run

1. Clone or download the GitHub repository.
2. Open the project folder.
3. Open `index.html` in any modern web browser.
4. Enter your running details and click **Calculate Run**.
